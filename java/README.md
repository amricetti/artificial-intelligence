# ☕ Java Enterprise Repositories & Architecture Showcase

> Coleção oficial de microserviços, arquiteturas de mensageria event-driven, Clean Architecture, DDD e projetos de alta performance em **Java 21** e **Spring Boot 3**.

---

## 📂 Projetos Disponíveis

### 🚀 [java-event-driven-architecture](./java-event-driven-architecture)
Microserviço Event-Driven de Alta Performance desenvolvido em **Java 21** e **Spring Boot 3.2**, aplicando os princípios de **Clean Architecture**, **Domain-Driven Design (DDD)**, Mensageria com **Apache Kafka**, Persistência Relacional com **PostgreSQL**, Migrações com **Flyway** e Orquestração com **Docker Compose**.

---

## 🛠️ Tecnologias Principais

- **Java 21 LTS** (Records, Virtual Threads, Pattern Matching, Sealed Classes)
- **Spring Boot 3.2+** (Spring Data JPA, Spring Kafka, Spring Validation)
- **Apache Kafka** (Producers, Consumer Groups, Event Sourcing)
- **PostgreSQL 16 & Flyway Database Migrations**
- **Docker Compose & Containerization**
